# RealJordan — Static Site

Single-page site for GitHub Pages.

## Local
Open `index.html` in a browser (no build needed).

## Deploy
1. Push to `main`.
2. In **Settings → Pages**, set:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
3. (Optional) Add custom domain and DNS `CNAME`.
